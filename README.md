# CK Premium — หน้าเช็กราคา (Quote Quiz)

ลูกค้าเลือกรุ่น → สี → วิธีทำโลโก้ → จำนวน → การจัดส่ง → ใบกำกับภาษี → วันที่ต้องใช้ → โลโก้ แล้วเห็นราคาทันที
จากนั้นเลือกส่งคำขอทางอีเมล หรือส่งรูปสรุปราคาเข้าแชทเพจ Facebook (ลูกค้าเป็นฝ่ายทักก่อน) ระบบคิดราคาจากตาราง ไม่มีค่า AI

## เปิดดูในเครื่อง
```
python3 -m http.server 8787
```
แล้วเปิด http://localhost:8787

## ไฟล์สำคัญ
- `js/data.js` — ข้อมูลร้าน: TBL-17/18/19 + สี, ราคางานพิมพ์, ชื่อไม่ซ้ำ, VAT และการตั้งค่า (`submitUrl`, `messengerPage`)
- `js/products-other.js` — ราคารุ่นอื่น 45 รุ่น สร้างจาก `../FAQ/CK_2_ราคา.txt`
- `js/pricing.js` — สูตรคิดราคา
- `js/app.js` — หน้าจอ quiz
- `js/summary-image.js` — วาดรูปสรุปราคา (PNG) ให้ลูกค้าบันทึก/แชร์ไปส่งในแชทเพจหรือแนบอีเมล
- `assets/` — รูปสินค้า (ย่อขนาดแล้ว), `source-images/` — รูปต้นฉบับ

## ตั้งค่าระบบรับคำขอ (Google Sheet + อีเมลแจ้งร้าน) — ฟรี ทำครั้งเดียว ~5 นาที
ระบบนี้ทำให้ลูกค้าที่เลือก "รับทางอีเมล" แค่กรอกอีเมล แล้วร้านได้รับคำขอทันที (ลูกค้าไม่ต้องกดส่งเอง)
และทุกคำขอ (รวมแชทเพจ) จะถูกบันทึกลงชีตให้ตามงานได้

1. ล็อกอิน Google ด้วยบัญชีร้าน (ckprintingth@gmail.com) แล้วสร้าง Google Sheet ใหม่ ตั้งชื่อเช่น "CK Premium คำขอใบเสนอราคา"
2. ในชีต ไปที่เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจากไฟล์ `tools/google-apps-script.gs` → กดบันทึก
4. เลือกฟังก์ชัน `setup` ด้านบน แล้วกด **เรียกใช้ (Run)** → กดอนุญาตสิทธิ์ (ชีต + ส่งอีเมล)
5. กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - เรียกใช้ในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) มาใส่ใน `js/data.js` ที่ `submitUrl: "..."`

ทดสอบ: ทำ quiz แบบรับใบกำกับภาษี → เลือกรับทางอีเมล → ควรมีแถวใหม่ในชีต และอีเมลแจ้งเข้า ckprintingth@gmail.com พร้อมรูปสรุป
กด "ตอบกลับ" ในอีเมลแจ้งเตือน = ตอบลูกค้าโดยตรง (แนบใบเสนอราคาแล้วส่ง)

> ถ้าแก้โค้ด Apps Script ภายหลัง ต้อง Deploy → Manage deployments → แก้ไข → เวอร์ชันใหม่ ทุกครั้ง

## แจ้งเตือนเข้า Telegram (ทำครั้งเดียว ~5 นาที)
ทุกครั้งที่ลูกค้ากด "ขอใบเสนอราคา" จะมีรูปสรุปราคา + รายละเอียดเด้งเข้า Telegram

1. **สร้างบอท** — ใน Telegram ค้นหา `@BotFather` → พิมพ์ `/newbot` → ตั้งชื่อ (เช่น CK Premium แจ้งเตือน) → ตั้ง username ที่ลงท้ายด้วย `bot` → จะได้ **token** (หน้าตาแบบ `123456:ABC...`) เก็บเป็นความลับ ห้ามใส่ในโค้ดเว็บ
2. **ให้บอทรู้จักแชท** — เปิดบอทที่เพิ่งสร้างแล้วกด **Start** (หรือถ้าอยากให้แจ้งเข้ากลุ่มทีม: เพิ่มบอทเข้ากลุ่ม แล้วพิมพ์ข้อความอะไรก็ได้ในกลุ่ม 1 ครั้ง)
3. **อัปเดตโค้ด Apps Script** — เปิด Apps Script ของชีตคำขอ → ลบโค้ดเดิม → วางโค้ดใหม่ทั้งหมดจาก `tools/google-apps-script.gs` → บันทึก
4. **ใส่ token** — ไอคอนเฟือง (Project Settings) → Script Properties → Add script property
   - Property: `TELEGRAM_BOT_TOKEN` Value: token จากข้อ 1 → บันทึก
5. กลับไปหน้าโค้ด → เลือกฟังก์ชัน `setup` → Run (อนุญาตสิทธิ์ "เชื่อมต่อบริการภายนอก")
6. เลือกฟังก์ชัน `findTelegramChatId` → Run → ดู **Chat ID** ใน Execution log → เพิ่ม Script Property `TELEGRAM_CHAT_ID` = ตัวเลขนั้น (กลุ่มจะเป็นเลขติดลบ ใส่เครื่องหมาย - ด้วย)
7. เลือกฟังก์ชัน `testTelegram` → Run → ควรมีข้อความทดสอบเด้งใน Telegram
8. **Deploy เวอร์ชันใหม่** — Deploy → Manage deployments → กดดินสอ (Edit) → Version: **New version** → Deploy (URL เดิม ไม่ต้องแก้เว็บ)
